Design a **stunning, premium website for "Orbital-AI"**, an interactive AI assistant for analyzing satellite and remote-sensing imagery through natural-language questions.

The visual identity must feel **human-designed, sophisticated, cinematic, and technologically advanced**, avoiding the generic look of AI-generated websites.

### COLOR SYSTEM

Build the entire interface around this distinctive palette:

* Deep Space Navy: `#07111F` - primary background
* Midnight Blue: `#0D1B2A` - secondary sections
* Electric Cyan: `#20D9FF` - primary interactive/accent color
* Solar Orange: `#FF9F43` - secondary accent and important highlights
* Mint Teal: `#35E0B8` - positive/status/data indicators
* Soft White: `#F4F7FA` - primary text
* Cool Gray: `#9AA9B8` - secondary text
* Blue-Black: `#101F30` - cards and panels

Use **cyan and orange strategically**, not everywhere. Cyan should communicate technology, intelligence, maps, and interaction. Orange should draw attention to important actions, discoveries, alerts, and key data.

DO NOT use the standard purple-blue AI gradient aesthetic.

### VISUAL DIRECTION

Create a visual language inspired by:

**satellite control centers + premium mapping software + modern editorial design + cinematic space imagery**

Use:

* Deep dark backgrounds
* Subtle atmospheric gradients
* Fine geographic/grid patterns
* Satellite imagery
* Topographic lines
* Coordinate overlays
* Small technical labels
* Data visualization
* Map-inspired UI elements
* Carefully controlled glow effects
* Subtle grain/noise texture

The interface should feel **rich and vibrant without becoming neon or childish**.

### HERO SECTION

Create an impressive asymmetric hero.

Left side:

* Small label: "REMOTE-SENSING VISION-LANGUAGE ASSISTANT"
* Large headline:
  **"Query Satellite Imagery. Understand What Changed."**
* Supporting text: "Upload satellite imagery and ask questions in natural language. SatQuery AI supports single-image visual question answering, bi-temporal change analysis, and optical-SAR image fusion, with an execution trace showing how each request is processed."
* Primary CTA using Electric Cyan.
* Secondary CTA using a subtle outlined treatment.

Right side:
Create a large satellite-image visualization showing a realistic Earth observation scene.

Overlay:

* Coordinate markers
* Detection boxes
* Small data labels
* Terrain classification
* Building/road indicators
* A floating natural-language query interface
* Small cyan and orange data points

The visualization should feel like an actual professional remote-sensing platform rather than a decorative illustration.

### PRODUCT INTERFACE

Create a large interactive dashboard preview.

Include:

* Satellite image viewer
* Zoom controls
* Layer selector
* AI chat panel
* Query input
* Detection overlays
* Statistics
* Land classification
* Building count
* Water coverage
* Vegetation percentage
* Change detection results

Use cyan for analytical information and orange for important detected changes.

### FEATURE SECTIONS

Do NOT create a repetitive grid of identical cards.

Instead use varied compositions:

* Large visual feature + small supporting features
* Full-width satellite image sections
* Split-screen layouts
* Data visualization sections
* Interactive map-style elements
* Before/after satellite imagery comparison

Show actual use cases such as:

"How much of this area is covered by water?"

"Are there any roads or buildings?"

"Has vegetation increased or decreased?"

"Compare this image with last year's image."

### DATA VISUALIZATION

Use clean charts and statistics with:

* Cyan lines
* Orange comparison indicators
* Mint positive trends
* Dark blue panels

Keep charts minimal and professional.

### TYPOGRAPHY

Use a modern geometric sans-serif for headings and a highly readable sans-serif for body text.

Large headings should have strong visual hierarchy but should NOT occupy the entire screen.

Include small uppercase technical labels and coordinate-style microtext to reinforce the satellite/GIS identity.

### NAVIGATION

Create a clean premium navbar:

Orbital-AI logo | Explore | Analyze | Features | About

Right side:
"Upload Image" and "Try Orbital-AI"

Keep the navbar elegant and compact.

### MICRO-INTERACTIONS

Include subtle:

* Image hover effects
* Data-point animations
* Smooth button transitions
* Map zoom animations
* Query loading animation
* Scroll-based reveals
* Soft cyan glow on active analytical elements

Animations should feel **precise and purposeful**, not flashy.

### IMPORTANT DESIGN RULES

Avoid:

* Purple AI gradients
* Excessive glassmorphism
* Excessive rounded cards
* Generic SaaS layouts
* Repeated 3-column card grids
* Huge meaningless text
* Random glowing blobs
* Stock AI robot imagery
* Excessive neon
* Overly futuristic sci-fi decoration

Instead create **natural asymmetry, editorial spacing, realistic satellite imagery, meaningful data visualizations, and strong branding**.

The final result should feel like a product created by a **professional geospatial technology company**, combining the sophistication of a premium SaaS product with the visual character of satellite science.

Overall impression:

**Dark. Cinematic. Intelligent. Vibrant. Precise. Premium. Human-designed.**

The website should make judges immediately understand:

**"This is an advanced satellite intelligence platform, not just another AI chatbot."**
